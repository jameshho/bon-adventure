# Original raw assets

This project started as fully procedural Godot geometry, not external Blender/FBX/PNG models.
Original source and unmodified project are preserved in `backups/Vocabulary_Town_v26_Original.zip`.
Use `.tscn` scenes under `scenes/` as the editable source of truth for migrated assets.
The older procedural generators remain in `scripts/world/` for locations not yet migrated.
No third-party asset pack or font files are included.
